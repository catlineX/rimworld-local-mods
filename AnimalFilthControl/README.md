# 动物污物系数调整

适用：当前安装的 RimWorld 1.6.4871 rev591。版本 1.0.0。

在「选项 → 模组设置 → 动物污物系数调整」中调整产生系数，默认 **10%**，范围 **0%～200%**。提供 0%、10%、25%、50%、100% 快捷按钮。

只调整动物的 `FilthRate` 属性结果，保留不同动物原本的速率差别。例如原速率 16 的动物，默认变为 1.6；原速率 1 的动物变为 0.1。野生和已驯服动物都适用，使用该属性的妖怪村动物也适用。人类、血迹、动物产物和其他模组独立生成的粪便物品不在调整范围内。动物脚上携带的污物另有机制，不保证完全消除。

已有污物不会被自动清除，仍需要清扫。设为 0% 只阻止本属性控制的新污物。属性有缓存，设置改变后等待刷新，必要时重新加载。

## 实现与加载

- 无 Harmony 依赖，不修改游戏原文件或 Workshop 模组文件。
- XML 向 `FilthRate` 的 `parts` 添加一个自定义 `StatPart`，只对 `RaceProps.Animal` 为真的对象乘以系数。
- 设置保存在游戏 Config 中，存档中不添加组件、物品、Hediff 或引用。
- 放在修改动物属性的模组之后，建议加载列表末尾。
- 与其他改污物速率的模组同用时可能叠加。另一个补丁如果替换整个 `FilthRate/parts`，本模组应放在其后。

## 回退

退出游戏，禁用本模组并重启，即恢复其他模组及游戏本身的污物速率。无需修改存档。已产生的污物不会因禁用而改变。

设置成100%只令本模组不再缩放，其他模组对污物的修改仍保留。

## 验证

已用当前游戏程序集编译。启动后日志应无本模组 XML/类型加载错误；选一只动物查看信息中的污物速率，分别测试100%、10%、0%，人类信息应不变。必须在游戏内完成该验证，编译通过不能证明所有其他模组组合均无冲突。

## 现成方案对比

- [No Animal Filth!](https://steamcommunity.com/sharedfiles/filedetails/?id=3502920947)：作者标注1.6，把所有动物的速率固定成1；并非可调倍率，也不是完全零污物。
- [Animal Filth? Don't Care](https://steamcommunity.com/sharedfiles/filedetails/?id=2573432875)：隐藏动物污物警告，不减少实际污物。
