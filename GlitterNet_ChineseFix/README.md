# GlitterNet 简体中文补全与校正

版本1.0.0，针对本机 GlitterNet 的 RimWorld 1.6 有效加载目录检查。

## 检查与修正

- 网络总览、设备分类、冬寂状态、任务统计及拆线按钮补全。
- 23种实际生效的中枢心情补全，使用当前 DefName 而非旧汉化失效键。
- 工作、地点、告别事件补全。
- 169条有效任务规则、说明、通知和进展文字补全；注释停用的扩网任务不翻译。
- 修正优化处理器误译、超频效率与效率上限混淆、并行数量“增量”误译、摄氏度和百分比单位遗漏。
- 保留既有建筑名称，统一“闪耀网络、算力、工程终端、科研终端、专用优化处理器”；Wintermute译为“冬寂”。CyberNet在总览中的分类译为“赛博网络”，不表示安装了该模组。
- `GNGenericMoodExited` 原文为拼写错误的 Exited，结合正向任务奖励心情语境译为“兴奋”，内部键不改。

主体为语言文件。另有一个使用 Harmony 的局部补丁，仅在中枢 GetGizmos 迭代器中将12处硬编码开发按钮标题/提示交给翻译系统；原版已依赖的 Harmony 不需额外安装。没有XML玩法补丁、上游程序集或游戏源码，不修改性能数值、触发条件、任务节点结构及存档。诊断日志、内部状态与存档键保留原文以方便排错。占位符、规则左侧名称及内部拼写错误（如 Efficieny/Networy）按上游保留。

## 验证

`Tests/Audit.ps1` 按 LoadFolders.xml 的1.6顺序解析有效文件，校验英文Keyed覆盖、DefInjected路径、格式占位符、任务规则标识及有效文本遗漏。人工复核英文原文与既有玩法定义。

静态检查不能代替真实游戏测试；启用后需检查总览窗口、设置提示及新生成任务。已有存档中已生成的任务文字可能是缓存，不一定被新语言文件替换。本文不承诺第三方动态生成文本或所有屏幕尺寸的布局均已验证。

## 安装与回退

游戏关闭后部署到 Mods/GlitterNet_ChineseFix；启用“GlitterNet 简体中文补全与校正”，放在 GlitterNet 和其他该模组汉化之后，重启。使用简体中文语言。

禁用补丁并重启即可回退，不需要改存档。按用户要求只通过 Git 管理，不新增独立文件备份。未指定发布许可，不创建 GitHub Release 或 Workshop 项目；仓库同步依照用户授权执行。
